## 📌 Overview

A complete AI-powered platform for generating, optimizing, evaluating, and improving digital marketing content using LLMs, Machine Learning, Sentiment Analysis, Trend Analytics, and Automated Retraining.

## 🚀 Features

- AI Content Generation
- Sentiment Analysis
- Trend Optimization
- A/B Testing
- Streamlit Dashboard
- Slack Notifications
- Google Sheets Integration
- Automatic Model Retraining

## 🛠 Tech Stack

- Python
- Streamlit
- Scikit-learn
- Transformers
- Groq API
- Gemini API
- Pandas
- NumPy
- Matplotlib
